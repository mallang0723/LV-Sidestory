# Side Story (사이드 스토리)

Side Story는 Lumiverse에서 단일 캐릭터의 별도 이야기를 생성·번역하고, 본편과 분리해 보관하는 비공식 확장입니다. 루미버스 요약을 기본 참고 자료로 쓰고, 필요하면 대화 원문 일부를 번호로 골라 더한 뒤 프롬프트를 확인하고 생성할 수 있으며, 결과 편집·JSON 백업·제한된 정적 HTML 표시를 지원합니다.

Lumiverse 공식 확장이 아니며, Lumiverse 팀이 만들거나 승인·보증·지원하는 확장이 아닙니다. 원본 ST-Sidestory의 모든 기능을 구현한 것은 아니며 실제 모델 응답 품질을 검증한 것은 아닙니다.

화면은 원작의 **Side Story / 내면 / 다면 · 보관함 · 설정** 구조를 따릅니다. 작성과 읽기를 분리하고, 좁은 drawer에서는 작성/결과를 전환합니다. 참고 자료는 루미버스 요약이 기본이고, 대화 원문은 목록을 불러오지 않고 번호로만 고르며, 보관함은 제목·내용 검색과 카드 목록으로 엽니다. 번역·편집·발췌·수동 복구는 결과 아래의 접힌 도구에서 사용합니다. 색상과 입력 요소는 루미버스 테마 변수를 사용하며, 호스트의 전역 화면이나 스타일을 바꾸지 않습니다.

자료 불러오기 → (필요하면) 참고 자료에서 원문 일부·World Book 엔트리 선택 → 연결 선택 → 프롬프트 미리보기 → 명시적 생성 확인 순서로 사용합니다. 현재 연결은 호스트 `connections.active` selector에서 선택하며, 사용할 수 없으면 직접 선택해야 합니다. 본편 채팅·Cortex·World Book을 수정하지 않습니다. 토큰 수와 근사 여부, 제외 자료를 미리보기에서 확인하세요.

번역은 결과와 연결, 언어를 선택하고 번역 프롬프트를 확인한 다음 실행합니다. 원문은 보존됩니다. HTML은 텍스트 구간만 전송합니다. 잘못된 JSON 또는 누락/중복 ID는 복구 자료로 보관하며 수동 segment JSON으로 수정할 수 있습니다. 8,000 입력 토큰 초과 번역은 거부합니다.

편집은 자식 결과를 만듭니다. 제거 전 전체 JSON을 내보내세요. schema 1 및 ST-Sidestory version 1/2 백업을 제한된 크기로 검증·변환합니다. 원본 tags/번역/lineage는 보존하며 상세 제한은 QA.md에 기록합니다. 가져온 호스트 ID는 재매핑 확인 전 사용하지 않습니다. HTML은 제한된 정적 태그만 표시하며 원본 스크립트를 실행하지 않습니다.

`npm test`, `npm run build`, `npm run qa:browser`로 검증합니다. Bun 경로는 `BUN_BIN`, Chromium 경로는 `CHROMIUM_BIN`으로 지정할 수 있습니다. ZIP에는 실행물·소스·vendor·출처·문서·테스트·합성 브라우저 harness(기능·작은 화면 배치)를 포함합니다. 실행기는 headless Chromium만 사용하며 일반 브라우저 탭을 자동으로 열지 않습니다.

소스 저장소 및 배포 안내: https://github.com/mallang0723/LV-Sidestory

## 설치와 빌드

Lumiverse의 확장 설치에서 GitHub 주소 `https://github.com/mallang0723/LV-Sidestory`를 입력하세요. 설치 후 필요한 권한을 확인·허용하고 확장을 활성화하세요. 제거 전에는 결과 JSON을 백업하세요.

GitHub 주소 설치에 필요한 `dist/backend.js`와 `dist/frontend.js`를 저장소에 포함합니다. 사용자가 직접 빌드할 필요는 없습니다. `src/backend.ts`와 `src/frontend.ts` 자동 빌드 진입점은 보조로 유지합니다. 소스를 변경할 때는 Bun 1.4.0으로 `npm run build`를 실행하고 갱신된 두 실행물도 같은 커밋에 포함하세요. 깨끗한 clone에서 재빌드해 실행물의 바이트가 일치하는지 확인하세요.

기능 제한과 검증 범위는 [QA.md](QA.md), 원저작물 출처와 허가 출처는 [NOTICE.md](NOTICE.md)를 확인하세요. [PolyForm Noncommercial License 1.0.0](LICENSE)에 따라 제공하는 비상업 source-available 소프트웨어입니다. 상업적 이용은 이 라이선스로 허용되지 않습니다.

설치 권한의 `chat_mutation`은 호스트의 대화 메시지 조회 API에 필요하며, 이 확장은 메시지 읽기에만 사용하고 본편 메시지를 수정하지 않습니다. 메시지는 “원문 일부 넣기”를 켰을 때 개수 확인과 미리보기에서만 읽고, 화면에는 개수만 표시합니다. World Book 연결 자동 탐색은 지원하지 않으므로 자료를 직접 선택해야 합니다.

설치 권한의 `presets`는 **프리셋 드롭다운에만** 필요합니다. Lumiverse 호스트에는 프리셋 읽기 전용 권한이 없어 이 권한을 허용하면 프리셋 쓰기(생성·수정·삭제)도 함께 허용됩니다. 이 확장은 프리셋 목록 조회와 단건 조회만 사용하며 프리셋을 만들거나 고치거나 지우지 않습니다. 권한을 허용하지 않으면 드롭다운에는 `없음`만 표시되고 나머지 기능은 그대로 동작합니다.

### 루미버스 요약 넣기

참고 자료의 기본은 요약입니다. “루미버스 요약 넣기”는 처음부터 켜져 있으며, 현재 채팅의 Loom 요약을 참고 자료의 요약 칸에 넣습니다. 요약이 없는 채팅이면 자료를 불러올 때 한 줄 안내가 나오고, “직접 요약”에 줄거리를 적어 쓸 수 있습니다. 직접 요약도 적었다면 `[루미버스 요약]`과 `[직접 요약]`으로 나누어 함께 보냅니다. 미리보기에 그대로 표시되며 입력 토큰 예산에 포함됩니다.

### 원문 일부 넣기

대화 원문은 기본으로 넣지 않습니다. 필요할 때 참고 자료의 “원문 일부 넣기”를 켜고 **최근 N개** 또는 **번호 범위**(시작–끝)를 숫자로 고르세요. 번호는 채팅 화면의 메시지에 표시되는 `#번호`와 같습니다. 메시지 목록을 불러오지 않으며, 켜는 순간 전체 개수와 넣을 수 없는 숨김·시스템 메시지 수만 확인해 “넣을 원문: 최근 대화 20개”처럼 한 줄로 보여 줍니다.

- 최근 N개는 넣을 수 있는 대화(숨김·시스템 제외) 중 마지막 N개입니다. 범위 안의 숨김·시스템 메시지는 빼고 미리보기의 제외 목록에 개수를 표시합니다.
- 시작과 끝을 거꾸로 적어도 작은 번호부터 읽습니다. 한 번에 500개까지 넣을 수 있습니다.
- 미리보기를 만들 때 현재 채팅 기준으로 번호를 다시 확인하므로, 그사이 대화가 줄어 범위를 벗어나면 미리보기를 거부합니다.
- 입력 토큰 예산이 모자라면 원문의 오래된 대화부터 빼고 요약은 그대로 둡니다. 뺀 개수는 제외 목록에 표시합니다.

### 프리셋

“프리셋”에서 루미버스 프롬프트 프리셋을 고르면 그 지시문을 Side Story 요청과 함께 보냅니다. 기본값 `없음`은 기존 동작과 같습니다. 프리셋의 켜진 일반 블록을 호스트의 블록 조립으로 매크로와 프롬프트 변수를 풀어 system 메시지로 앞에 붙입니다. 빠진 블록과 이유는 미리보기의 제외 목록에, 주의 사항은 `notices`에 표시되고, 프리셋 지시문은 입력 토큰 예산에 포함됩니다. 선택한 프리셋은 기억됩니다. 번역에는 프리셋을 적용하지 않습니다.

지원 범위는 다음과 같습니다.

- **classic 엔진 프리셋만 지원합니다.** 호스트 블록 조립은 원 프리셋을 그대로 실행하지 않고 classic 방식의 임시 프리셋으로 블록만 조립하므로 원 엔진 동작과 원 프리셋 metadata를 이어받지 않습니다. classic이 아닌 엔진의 프리셋은 목록에 `미지원`으로 표시되어 고를 수 없고, 미리보기도 거부합니다.
- **봉인 블록(LumiHub 봉인 프리셋의 `{{presetBlock::…}}`/`{{pblock::…}}`)은 지원하지 않습니다.** 원 프리셋 정보 없이는 풀 수 없어 빼고, 해당 프리셋은 목록에 `부분 지원`으로 표시됩니다. 블록 본문이 `{{var::…}}`로 부르는 저장된 프롬프트 변수 값에 봉인 매크로가 있어도 같은 기준으로 표시합니다.
- **append 블록(user_append·assistant_append)은 지원하지 않습니다.** 호스트는 이 블록을 대화 기록 marker로 들어온 마지막 메시지에 붙이는데, Side Story는 대화 기록 marker를 넣지 않아 붙일 곳이 없습니다. 생성 조건으로 빠진 블록과 구분해 `미지원`으로 표시합니다.
- 목록 표시와 미리보기 판정은 같은 기준을 씁니다. 봉인·append·호스트 자료 매크로 때문에 빠지는 블록이 있으면 `부분 지원`, 보낼 블록이 하나도 남지 않으면 `적용 안 됨`으로 표시합니다. `적용 안 됨` 프리셋을 고르면 미리보기에 프리셋 지시문이 적용되지 않는다는 주의 사항이 표시되며, 생성 조건으로 모든 블록이 빠진 경우도 같습니다.
- chat history·world info 같은 marker 블록은 Side Story가 참고 자료를 직접 구성하므로 넣지 않습니다.

**프리셋 매크로와 자료 경계.** 프리셋 블록의 매크로는 호스트가 현재 채팅의 캐릭터·페르소나·대화·기억 등으로 펼칩니다. 그래서 프리셋을 쓰면 “선택한 자료만 보낸다”는 보장이 프리셋 지시문에는 적용되지 않습니다. 알려진 호스트 자료 매크로(`{{memories}}` 등 기억·Cortex·데이터뱅크, 대화 본문, 캐릭터/페르소나 카드, `{{wiMarker}}`·outlet 같은 World Info 출력, Loom 요약, 웹 검색, 채팅·전역 변수)가 블록 본문이나 프롬프트 변수 값에 있으면 그 블록을 통째로 빼고 이유를 표시합니다. 채팅·전역 변수에는 `{{getchatvarkey}}`·`{{getgvarkey}}`(별칭 `getglobalvarkey`·`getglobalvarindex`) 같은 JSON 경로 읽기도 포함됩니다. 다만 이 검사는 Lumiverse 1.2.5 기본 매크로 이름에 기반한 것으로 전수 검사가 아닙니다. 알려진 누락으로, 다른 확장이 추가하거나 가로채는 매크로, 문자열 결합 등 재귀 확장으로 만들어지는 매크로 이름, 다른 블록의 변수를 거쳐 들어오는 값은 막지 못하며, `{{char}}`·`{{user}}`처럼 허용되는 매크로도 캐릭터·사용자 이름을 넣습니다. 생성 전에 미리보기의 system 본문을 확인하세요.

**임베딩 요청.** 프리셋 지시문을 만들 때 호스트 프롬프트 조립을 거칩니다. 임베딩이 켜져 있고 현재 채팅에 활성 데이터뱅크가 있으면, 조립 준비 단계가 데이터뱅크 검색용으로 현재 채팅의 최근 메시지 최대 6개 본문을 이어 붙여 설정된 임베딩 공급자로 보낼 수 있습니다. “원문 일부 넣기”로 고르지 않은 메시지도 포함됩니다. 같은 내용이 호스트 캐시(약 10분)에 있으면 외부 요청이 생략될 수 있고, 미리보기를 다시 만들 때마다 다시 시도합니다. 기억 검색 등 다른 조립 단계도 임베딩을 요청할 수 있어 미리보기마다 요청 횟수가 정해져 있지 않습니다. 프리셋이 `없음`이거나 보낼 블록이 없으면 호스트 조립을 호출하지 않습니다. 모델 생성 요청은 미리보기 단계에서 보내지 않습니다.

핵심정보는 결과 화면에 항목별 문서로 표시되며, 저장된 구조화 JSON은 편집 초안과 “핵심정보 검토”에서 확인할 수 있습니다. 검토 후 “핵심정보로 선택”으로 승인하면 AU에 사용합니다. 다른 텍스트 작업은 JSON이 아닌 글로 답하도록 요청하고, 모델이 JSON으로 답하면 화면에서만 읽을 수 있는 글로 바꿔 보여 줍니다. 생성·번역 요청은 호출 전에 durable journal을 기록하며 불명확한 요청을 자동으로 재과금하지 않습니다.

저장 실패 후 같은 런타임의 미취소 요청은 재과금 없이 저장을 재시도할 수 있습니다. 재시작 후 record에 저장되지 않은 journal 결과는 취소 여부를 입증할 수 없어 자동 복원을 거부합니다. 원문 journal은 남지만 수동 복구 UI는 없습니다. 이미 저장된 결과의 재조회는 정상 지원합니다.
